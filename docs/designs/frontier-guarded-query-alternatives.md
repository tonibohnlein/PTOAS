# Optional Boolean spelling of guarded rank queries

This source batch keeps the original numeric rank query and its captured-input
and publication ownership. It can retain a smaller Boolean spelling for the
bounded extended-window producer and try that spelling when emitting an incoming
prefix expression. Source review and execution acceptance are separate; no Delta
speed, emitted-size, capacity or milestone-completion claim follows from this
implementation alone.

## Exact query construction

Only a Reference-labelled reducer explicitly asked to retain its original graph
owns projection evidence. Other reducers retain their previous construction.
The immutable evidence contains the validated original incoming generators,
presence predicates and pipe columns, rather than the reduced cover edges.

The query-local projection tracks separate start and completion reachability on
each native pipe. An absent potential occurrence leaves both registers unchanged.
A completion can reach a later same-pipe completion but does not thereby reach
that occurrence's start. The result retains source and target presence. Numeric
cover construction, ranks, native-distance and far-query behavior remain intact.

The candidate keeps the exact original opaque Input identities. Eligibility
inspects every guard arm and admits only the explicitly listed total scalar
vocabulary; Integer recipes and unknown future kinds remain on the original
route. A candidate with additional referenced inputs or no strict reduction in
reachable pre-binding DAG nodes is discarded transactionally. This is an optional
representation choice, not a solver cutoff or a new analysis refusal. The node
comparison is not a prediction of total emitted or constructed operations.

## Ownership and transport

The arena owns a map from original roots to trusted equivalent alternate roots.
It does not own callbacks, detached SSA or replacement-target memos. A journal
removes speculative registrations even when both IDs predate a transaction.
Only the internal exact projection producer establishes new equivalences; the
registry's structural checks alone are not a proof of arbitrary equality.

Ordinary expression use continues to return the original root. Input-only
simultaneous substitution may transport a relation, with a fresh substitution
context for its alternate. Both resulting spellings are rechecked against the
supported total vocabulary, exact input subset and size criterion. Internal-node
replacement does not transport equivalences. Import uses the existing original
Input/evaluation ownership and metadata checks. Optional transport failure leaves
the successful original substitution/import unchanged. No optional target is
recursively substituted through another target in the same replacement.

The bounded regional binder may receive normalized composite predicate keys.
It preserves the original mixed substitution result, then qualifies an Input-only
context: every composite target must reconstruct exactly from its source under
that context, and the entire original root must reconstruct the exact mixed
result. Only then can the existing query relation pass through the Input-only
transport service. Unknown or unequal reconstructions retain the original path.
This qualification establishes redundancy of those composite entries; arbitrary
internal replacements still carry no equivalence evidence.

## Late qualification and exact fallback

Preparation collects captures and original input bindings once from the original
root. Emission first constructs an optional spelling in an arena transaction and
runs the unchanged direct, inactive and historical qualification on that spelling.
Its scalar operations stay in the existing detached scratch block until success.
Only successful emission publishes generated values to the exact cut, insertion
block, mapping and historical-state cache. A failed attempt can prepare read-only
original bindings, but publishes no generated SSA or proof conclusion. It restores
arena errors and speculative IDs before calling the original route.

The alternate must prove its own availability. Exact equivalence and an input
subset do not substitute for that proof. Consequently an expression which the old
shape-sensitive prover refused may now succeed when the alternate independently
passes the existing complete qualification. The tests distinguish this justified
success from the converse case, where the alternate refuses and the original
still succeeds. No conservative protocol or changed source cut is substituted.

## Work and acceptance gates

Profiling records alternate attempts, successful attempts, fallbacks and optional
preparation visits. A separate cumulative producer-construction section counts
owned graph copies and totality scans, query attempts and outcomes, projection
visits and newly interned nodes, and registration attempts and qualification
visits, including rejected work. Imported diagnostic owners are deduplicated;
these counts cover their entire arenas, not exclusive work of one emitted root.
They survive rollback and are separate from the latest emission attempt. Numeric
query construction is performed once per producer request, not repeated solely
to obtain the candidate. The existing constructed-operation counter includes failed
candidate emission as well as successful fallback emission; retained operations
count only committed scalar output. The original numeric reducer is still built.
The optimization therefore targets the consumed query and emitted scalar DAG,
not removal of the numeric analysis itself.

Source controls include all four event-kind pairs against an independent dense
graph closure, absent occurrences, native edges, duplicate generators, opaque
input preservation, exact fallback, typed transport refusal, nested transaction
rollback, imported evaluation identity, and shared emission-cache lifetimes.
Fresh compilation, focused execution, original protocol replay, and paired Delta
wall-time/RSS/constructed-and-retained-control evidence are required before a
production improvement claim. The untouched numeric route remains available
whenever optional qualification or emission fails.
