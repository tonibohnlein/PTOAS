### Recurring key binding: disjoint token lifetimes

Partial FIFO facts expose another allocation restriction in prefill: additional
logical channels can exhaust the private-key assignment and discard existing
protocols. The missing fact is whether two logical token streams overlap, not
whether they came from a FIFO. The shared control graph and exact ordered
endpoint words supply a finite matching monitor. It tracks the logical owner of
each live token, including alternative paths and backedges. A reused physical
key must retain each logical publication/acquisition match; empty occupancy
alone is insufficient. The mandatory causal proposal check separately proves
consumption knowledge before every republication. No acknowledgment is added
to make a proposed reuse succeed, and no endpoint moves.

Construction will retain the existing first-free assignment, then consult this
monitor when a direction runs out of private keys. This is a deterministic
binding policy, not a search over completed plans. It does not yet solve ordinary
residual allocation or prove an optimal coloring. Fixed reservations stay owned.

The prefill failure is specifically unavailable FIX/MTE2 direct primitives,
not exhaustion of an existing directional pool. Direct realization selection
must preserve complete coupled protocols before replacement or return sharing;
unrealized relations remain storage obligations. This restores the old bank
protocol while retaining partial FIFO facts. Recurring relay realization is
still a separate unfinished constructor mechanism.
