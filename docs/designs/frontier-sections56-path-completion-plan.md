## M1 — Retained ownership and capability upgrades

owners, and keep issued immutable owners valid. Replace parent inspection of
finite/sequence internals with provider-owned completion-child capabilities.
Consolidate scalar-free immutable family fragments and fresh mutable inventory
instantiation; retain separate direct-recipe and resource-empty qualifications.

requests, preserving the original mathematical owner and each protocol's own
allocation evidence.

Acceptance: parent-first/child-upgrade agrees with child-first for equivalent
capabilities; old plans remain valid; repeated requests do not reconstruct;
no generated SSA or mutable plan is cached. Delete superseded capture adapters.

## M2 — First-demand alternatives and specialized exports

Replace full strict-reachability self-composition with the revised first-demand
alternative-path construction in the existing DBM and integer reducers. Retain

Acceptance: generator-deletion and old cover-composition oracles, zero/one-pipe,
presence, residues, finite boundaries and qualified native extensions. Record

including eventful visits only with closed matching and certified physical

## M5 — Loss certificates and conformance

Expose immutable realized-order bounds. For appending counts (u, U_R) to (n, U),
use (n+u, U+U_R+n*u), with the default cross lower count zero. Retain symbolic
branch/visit counts; do not solve arbitrary while counts or add runtime analysis.
Zero child loss requires realized equality. Reuse periodic excess certificates
for stronger qualified bounds; missing lower support and overflow remain explicit.

Acceptance: enumerated actual-loss oracle, exact zero, quadratic examples,
missing lower support, branches and overflow. Publish a section-to-code table
with premises, production callers, missing capabilities, oracles and scaling.

## Delivery and scope

Implement counters and tests during each milestone. Measure inspected work,
constructed code and live code separately. Use three interleaved baseline and
candidate timing pairs on affected production cases; finish with the complete
synchronization gate and 49 primary modules against the pinned baseline. Saved,
combined and ordinary logical routes remain covered. No device claim without
separate execution. Review and commit substantial milestones before proceeding.

Runtime streaming, unrestricted synthesis, alternative notification protocols,
and a target-specific coordinator completion backend are outside this plan.
No weakening of retained exact results, extra barriers, arbitrary cutoffs, or
relaxed test expectations is permitted to meet a performance target.
