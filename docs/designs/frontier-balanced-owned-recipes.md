# Balanced compact owned recipe migration

The balanced compact producer now retains its counted trip count, source ordinal
and per-side activity as common contextual family expressions. It prepares no
scalar SSA. The common materializer chooses live inputs after allocation, and
the previous dedicated scalar preparation implementation is removed.

The migration preserves the original retained periodic records, directed pipes,
displacements, minimum-record namespaces, and each side's ordered original
alternative cuts. SET remains active exactly when the matching target visit
exists; WAIT and local-barrier activity retain the original displacement guard.
The source ordinal at WAIT remains its own visit minus the displacement. The
existing counted-loop qualification and enclosing-context refusals are unchanged.
No source/target alternative pairs are enumerated.

Saved schema 4 adds an owned loop-partition table. Rows bind a family and side to
an original loop in the sealed source directory and to an ordered list of original
cuts. Decode runs `qualifyEndpointCutChoices` again and validates exact endpoint
coverage. It does not infer a new allocation proof from the archive. Existing
schema 1–3 readers remain supported; schema 4 can retain both loop partitions
and the existing pending terminal-cleanup contract. Private captured state,
borrowed callbacks, and arbitrary concrete preparation remain unsupported.

The new control uses the actual balanced producer on original tile accesses,
with the existing two-edge periodic fixture and existing allocation export.
It compares ordinary logical, ordinary allocated split, combined, and
saved/default-print/reparsed allocated output. The independent command graph
checks native order, matching, reuse and all payload-event reachability; explicit
checks verify source record/ordinal/member and notification counts. Cases include
empty and partial invocations, original alternating arms, and signed lower −2
with nonunit step 3. The saved producer owners are destroyed before decoding.
Eleven resealed corruption cases check family/side/loop/cut ownership and atomic
refusal. Existing partition and malformed-allocation controls remain in place.

The frozen native build passed, and all 51 focused checks passed, including
the balanced producer, compact allocation, combined/saved pipeline and runtime
endpoint controls. Pinned source, retained tools and lit results are recorded in
`.local/milestone-loop/cofactor-repair-gate/`. Production campaign refresh remains
pending. This bounded migration does not claim a measured speedup, a new
capacity certificate, device-kernel compilation or full milestone completion.
