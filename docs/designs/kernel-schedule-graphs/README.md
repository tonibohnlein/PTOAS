# Kernel schedule graph examples

These DOT and SVG files are generated by `pto-print-kernel-schedule-graph`
from existing PTOAS regression kernels. They are review artifacts for the
initial whole-kernel scheduling graph, not hand-simplified diagrams.

- [Linear load/compute/store chain](linear-chain.svg): `linear_chain` from
  `test/lit/pto/graph_sync_solver_basic.pto` (3 nodes, 3 structural edges).
- [Loop with if/else](loop-if-else.svg): `loop_if_else_loop_carried_sync` from
  `test/lit/pto/issue454_loop_if_else_loop_carried_sync_regression.pto`
  (9 nodes, 31 structural edges).
- [Nested backedge case](nested-backedge.svg):
  `backedge_nested_same_pipe_prune` from
  `test/lit/pto/backedge_nested_same_pipe_prune_regression.pto`
  (10 nodes, 37 structural edges).

Blue nodes are transfer operations and amber nodes are compute operations.
Green, orange, and red edges are RAW, WAR, and WAW memory dependencies.
Purple edges are conservative control dependencies. Dashed edges are
positive-distance loop recurrences and do not belong to the structural DAG.

Regenerate an individual graph with:

```bash
pto-test-opt INPUT.pto '-pto-print-kernel-schedule-graph=format=dot' \
  | sed -n '/^digraph /,/^}$/p' > graph.dot
dot -Tsvg graph.dot -o graph.svg
```
